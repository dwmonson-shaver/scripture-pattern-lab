# CONV-002 — Architecture, DSL, and Retrieval Model

## Source Type
Conversation-derived synthesis

## Summary
This evidence note captures the rationale for a hybrid architecture and formal query language. The discussion argued that embeddings and RAG are useful but secondary to a deterministic symbolic engine.

## Key Takeaways
- Symbolic retrieval is the core engine.
- Embeddings help with concept expansion, not exact sequence proof.
- DSL should be readable, layered, and validated.
- Expansion, supersequence, and subpattern analysis matter.
